# projectM starter presets

A starter subset of 100 presets (10 per category) from projectM's
"Cream of the Crop" collection, curated by ISOSCELES:
https://github.com/projectM-visualizer/presets-cream-of-the-crop
(commit 0180df21f5e0bd39b9060cc5de420ed2f1f9e509, 9,795 presets in total).

Used by the experimental projectM renderer. Selection: random per
category, limited to presets that don't need the separate texture pack,
and each one checked to render non-black output with libprojectM 4.1.8.
See LICENSE.md for the collection's licence notes.
